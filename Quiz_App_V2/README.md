# Quiz App V2 🧠

A terminal-based Quiz App built with Python.

## Features

- Multiple-choice quiz questions
- User input validation
- Prevents invalid options
- Score tracking
- Countdown before checking the answer
- Separate function for asking questions
- Final score display
- Clean terminal-based interface

## Concepts Used

- Functions
- `while` loops
- `for` loops
- `range()`
- `time.sleep()`
- Conditional statements
- User input validation
- `.upper()`
- Function parameters and return values
- Variables and score tracking

## What I Improved in V2

This version was built to strengthen my understanding of Python functions, loops, input validation, and program structure.
